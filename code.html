Course Syllabus & Description

Comprehensive exploration of fundamental data structures including self-balancing binary search trees, hash tables, heaps, and directed acyclic graphs. Emphasizes rigorous Big-O algorithmic performance analysis.

  • Weekly 2-hour compiler lab attendance required in Turing Room 108.
